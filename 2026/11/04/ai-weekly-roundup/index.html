一、海外旗舰与新品（本期主线）

1. 🔑 Kimi K3.1 Pro（10-24 发布）——全球最大开源模型，3 万亿级参数 + 1M 上下文
K3.1 系列的第一个模型，也是月之暗面迄今能力最强的 3 万亿级参数模型（2.8T 总参 / 104B 激活 MoE），1M token 上下文，继续是全球参数规模最大的开源模型。Artificial Analysis 智能指数 55 分列全球第 4、开源模型第一（仅次于 Claude Opus 5.5 的 58）。Terminal-Bench 4.0 得分 65.7%，超 GPT-6 Astra（58.2%），与 Claude Opus 5.5（66.4%）仅微弱差距；Kimi Code Bench 3.0 Long-horizon 61.2%（K3 为 55.95%）。API 定价 $2 / $10，为 GPT-6 Astra 的五分之一。同步推出 Kimi K3.1 Pro Highspeed（同等智能、输出速度约 2~3 倍）。完整模型权重于 11-04 前发布——发布即通过 kimi.com、Kimi App、Kimi Work、Kimi Code 与 Kimi API 接入；新接入 Gmail / Google Drive / Google Calendar（安全 OAuth，可自动汇总邮件、检索文件、规划日程）。长程编码与 3D 创作是主打：官方演示用 Unreal Engine 5.8 + Blender 程序化建模 36M 三角面场景、用 Godot 4.7.2 构建 3D 动作游戏；金融方向在 Office QA Pro v2 与 SpreadsheetBench v2 两项测评取得全球最佳（超 Opus 5.5、Fable 5.1、GPT 6 Astra）。

2. 🔑 Mistral 正式开放 Large 4 权重（10-30）——「Le Chonk」万亿参数
1 万亿总参 / 52B 激活的原生多模态 MoE，1M 上下文，在欧洲训练，可免费下载（商用需单独授权），号称最佳开放权重编程与防御性网络安全模型，对恶意请求拒答率约 96.6%。

3. 🔑 DeepSeek V4.1-Flash-1017 开放权重——AA 智力指数升至 45 分，开放权重并列第 2
较前版升 6 分；Terminal-Bench 4.0 由 31.2 升至 42.3、DeepSWE 77.0，超过 Opus 5（74.0）与 GPT-5.6 Sol。延续「低价 + 开源 + 开放权重」路线。同期 Search & Fetch API 正式上线（11-01 起计费，见第三节）。

4. MiniMax M3.1 Flash 权重开放（10-23）——Agent 成本降约 70%
约 23B 激活（MiniMax 口径总 428B、HF 计 220.5B）的开放权重多模态 MoE，1M 上下文、五档推理常开，输入 $0.15/M，Agent 任务综合成本较前代下降约 70%，Automation-Bench v1.0.6 居首（62.2）。同期推出 Hailuo 2.3 视频模型。

5. OpenAI 时隔 6 年再开源推理模型
gpt-oss-120b / gpt-oss-20b，Apache 2.0；120b 版本性能与 o4-mini 相当、可在单张 H100 运行，20b 版本仅需 16GB 内存（支持手机部署），支持配置推理投入、完整思维链与智能体能力。同日（10-29）Pro 订阅 100 / 200 / 500 三档用量上限全部翻倍、价格不变，部分档位另获 API 额度。同期公开 722 篇内部前沿模型数学研究手稿。

6. DeepSeek 旧 ID 退役与 Search & Fetch 收费
官方明示 deepseek-v4-flash-vision-exp 等旧 ID「仍被接受，但对应模型已退役，请求由 DeepSeek-V4.1-Flash-1017 服务并按 Flash 价计费」。Search & Fetch API 正式上线：Search / Fetch 均 $0.75 / 1000 次成功请求；经 DeepSeek Harness / Claude Code / Codex 的服务端工具调用同样命中——11-01 起的收费窗口已生效，重度工具调用的成本核算必须补上这一项。

三、产业、算力与安全

1. 🔑🔑 英伟达「49% 算力红线」（11-03，FT 报道）——出口管制从「芯片跨境」延伸到「算力服务跨境」
英伟达近期通过销售与各地区团队口头向全球数据中心与云计算客户传达：未来新签算力服务合同中，至少 51% 的服务必须出售给非中国企业，中国客户占比原则上压缩至 49% 以内。适用范围覆盖全球、不限亚洲机房，仅约束未来新签合约、存量租赁不追溯，且未提供书面文件。英伟达未直接确认该比例，对外表述强调「采用美国芯片建设的数据中心和云服务是美国模型与应用开发商参与全球竞争的重要基础」。政策评论者 Chris McGuire 批评该阈值——既然受管制芯片不能直接卖给中国企业，通过海外数据中心远程租用算力理应也不被允许，合理阈值应是零。

  • 稀缺度定价：一套 B300 机柜国际市场售价约 60 万美元，而 10 月中国非正式市场成交价高达 1850 万元人民币（约 280 万美元），溢价约 4.67 倍。
  • 政策脉络连贯：7 月起英伟达已通过新版「白名单」将获准采购 AI 芯片的亚洲客户数量削减逾半，重点审查专营 GPU 出租的云服务商（实地检查机房、核实合同、追踪最终用户）——白名单收缩堵住采购端，49% 红线在租赁端收口。
  • 受压最直接的三类主体：依赖海外算力租赁的中小 AI 公司（可用算力减少、价格与排队周期上升）、东南亚 / 中东的第三方算力服务商（新加坡机构称在美国以外难找足够非中国客户，或被迫缩减数据中心规模）、靠价差转租算力的中间商与转售渠道。已在海外自建集群的头部厂商受影响相对有限。
  • ⚠️ 仍未明确：51% / 49% 的统计口径（算力容量、GPU 卡时、营收还是客户数量）尚无统一标准，且因口头传达，各区域落地节奏可能存在差异。

2. Saudi Aramco 收购 HUMAIN 49% 股权（11-01）
PIF 保留 51%。Aramco 将于 2026 年投入约 99 亿里亚尔（26 亿美元）现金，并以 AI、算力与数字资产及人才出资。HUMAIN（2025 年 5 月成立）构建数据中心、高性能云与模型（含多模态阿拉伯语 LLM ALLaM）的全栈，计划 2030 年前约 3GW AI 数据中心产能。Aramco 称自 2023 年以来已实现约 113 亿美元「技术实现价值」。

3. 四巨头共同支持 robots.txt 的 AI 训练偏好信号
Google、Microsoft、OpenAI、Anthropic 共同支持经 IETF AIPREF 工作组推进的共享 robots.txt 策略 token（usage_ai-training），让站点一次性声明内容是否可用于基础生成模型训练。Google 称若站点使用该共享退出项且未单独指定 Google-Extended，将按 Google-Extended disallow 处理，目标 2027 年支持；Microsoft 计划 2027-02-01 起遵守新的训练 / grounding 偏好并逐步废止旧的 NoArchive / NoCache 语义；OpenAI 表示「未来数月内」落地。
