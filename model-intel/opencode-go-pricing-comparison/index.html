OpenCode Go 定价、请求数与性价比测算（2026-11-26）

  • 模型情报
  • OPENCODE-GO-PRICING-COMPARISON

Go 内部价、请求数上限、峰谷时段与月等效价值测算。数据抓取日 2026-11-26。

← 返回「模型情报」合集

数据来源：OpenCode Go 清单 API GET https://opencode.ai/inference/go/v1/models（首选权威源，单次返回单价 / 三档月额度 / ZDR / 峰谷倍率 / 上下文，无需登录）、Console Go 页 opencode.ai/console/go（公开页，HTTP 200）、官方文档 opencode.ai/docs/go、OpenCode Zen 清单 API（108 款）、CommandCode Provider API（105 端点）/ CLI 1.93.4 目录（105 款，差集 0）、OpenRouter 模型与 endpoints API（目录 474 款）、各厂商官方 API 定价页（DeepSeek / 智谱 / Kimi / 小米 / MiniMax 本轮实测）。
折算汇率：1 美元 ≈ 6.7096 元人民币（中国外汇交易中心 2026-11-26 09:15 中间价；第三方交叉校验 6.6757 / 6.6782，偏差 0.47% < 1%）。
现行口径：三档订阅——Go $10/月、Go Plus $40/月（Higher usage limits）、Go Teams $20/成员/月（逐模型额度 = Go + $5）。三档 Token 单价完全相同，仅月度额度上限不同。
🔑 额度语义（必读）：所有付费模型共用一个额度池——官方原文 “share one allowance” / “Switching models draws from the same allowance”。逐模型 Monthly limit 是**”若把全部额度只花在这一个模型上”的分母**，不可相加。
目录口径：清单 API 37 个 ID = 31 款文本（27 付费 + 4 免费）+ 3 款 decision + 3 款 embedding；Console Limits Tab 显示 32 行（含 1 行过期 GLM-5.2 残留）——以 API 为准。
Plus 倍率：文本模型 2x / 3x / 4x 三档，上限即 4x；Teams 恒为 Go + $5（加数，非乘数）。decision / embedding 例外：Go $10 / Plus $40 / Teams $15，无逐模型倍率。

  • 现行 7 档分布：$10（6 款，decision / embedding）、$15（10 款，旗舰/新模型）、$20（1 款，minimax-m3.1-flash）、$30（3 款）、$60（11 款，成熟主力）、$100（1 款，deepseek-v4.1-flash）、$200（1 款，glm-5.3）。

  • ⚠️ decision / embedding 的 $10 档没有折扣：官方原文 “come at list price, with no Go discount: their monthly limit matches what you pay, $10 on Go and $40 on Go Plus. On Go Teams it’s $15”。
  • 为什么部分模型额度低（官方 “Why some models have lower usage”）：多数模型靠批量折扣 + 预留 GPU 容量换取高月额度；新模型或公开价本身已打折的模型无折扣空间，其额度只是”略高于直付厂商”。
  • 客户端要求：① 发送典型 coding agent 流量；② 自带 user agent；③ 每个会话发送稳定的 x-opencode-session；decision / embedding 请求不需要该头。
    • 已验证客户端：OpenCode、Hermes（v0.21.6+）、Claude Code、Codex、ZCode、Pi、jcode（v0.81.6+）、Kilo Code CLI（PR #13752，不覆盖 VS Code 扩展）。
    • 已知有问题：DeepSeek Harness、GitHub Copilot Chat、Kimi Code、MiMo Code。
  • 超额处理：达月限额不自动回落，可手动切免费模型，或开 Extra Usage 按量计费。响应头 opencode.allowance 回报本次请求计入额度的金额。
  • 订阅范围：Go / Go Plus 仅限单成员 workspace；Go Teams 为 $20/成员/月、2 成员起（最低 $40/月），第二席位覆盖下一个加入者免费，期中加入收 $20 获全额，服务账号不覆盖。三档均可用 workspace credit 支付。
  • 端点路径：https://opencode.ai/inference/go/{openai,anthropic,google,systemone}/v1*，模型清单 .../inference/go/v1/models。旧 zen/go/v1/* 仍返 200（兼容别名）。

九、关键发现（现行结论）

  1. 逐模型价目与请求数已完全公开：清单 API 单次返回 cost / go.monthly_usage 三档 / limit / capabilities；Console Go 页为公开页。
  2. 额度是”月度美元 + 比例窗口”：5h = 20%、周 = 50%、月 = 100%，所有付费模型共用一个额度池——逐模型数字不可相加。
  3. 🔑 Plus 上限就是 4x，且 4x 恰好是盈亏平衡点：4x 持平（16 款）、3x 贵 33%（5 款）、2x 贵 100%（6 款）。清单内没有 5x 及以上。
  4. Teams 是加数不是乘数：$15 档 +$5 → 1.33x 额度（0.67x 单位价值），$200 档 +$5 → 1.03x（0.51x）。
  5. glm-5.3 已回落 $200，不是 $15：促销结束后官方给的是 $200（Plus $400），20.0x 仍是全目录第一；Plus 对它仍是 2x（单位价值腰斩）。
  6. kimi-k3.1-pro 额度上调至 $60（API）：从 1.5x 档跃升为 6.0x，与 glm-5.3-flash / kimi-k2.7-code 同档；Console 仍显示 $15/$60，需以 API 为准。
  7. 新增 decision / embedding 两类 6 款：$10 档、按量等价、无折扣、无需会话头；这是 Go 从”编码订阅”扩展到”RAG / 决策基础设施”的信号。
  8. gemini-4-argon 12-01 起翻倍：$2/$10/$0.10 → $4/$20/$0.20，额度不变，等同请求量腰斩。
  9. DeepSeek 侧版本与价格未变：DeepSeek-V4.1-Flash-1017 与 DeepSeek-V4-Pro-0813 两行；Go 侧 deepseek-v4.1-flash $100、216,500 次/月、10.0x。
  10. Kimi K2 系列 12 月底下线：kimi-k2.7-code 属 K2 系列，长期配置应迁移到 K3 / K3.1 Pro。
  11. 免费层 4 款：beam-free（限地区）、hy4-flash-free（ZDR）、hungerg-free（新、ZDR）、iceman-contributor-free（训练）。不自动回落，需手动切模型 ID。
