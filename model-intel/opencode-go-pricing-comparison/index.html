OpenCode Go 定价、请求数与性价比测算

  • 模型情报

Go / Plus / Teams 三档额度、逐模型请求数上限、峰谷时段与月等效价值测算。数据抓取日 2026-11-22。

← 返回「模型情报」合集

数据来源：OpenCode Go 清单 API GET https://opencode.ai/inference/go/v1/models（首选权威源，单次返回单价 / 三档月额度 / ZDR / 峰谷倍率 / 上下文，无需登录）、Console Go 页 opencode.ai/console/go（公开页，HTTP 200，无需登录；四 Tab = Limits / Pricing / Privacy / API，Tab 走 hash 路由 + 客户端渲染）、官方文档 opencode.ai/docs/go（现为 5 张表：套餐表 / 客户端 Session support / 客户端 Status / 字段说明 / Model & Data retention）、官方营销页 opencode.ai/zh/go、OpenCode Data（opencode.ai/data）、OpenCode Zen 清单 API（105 款）、CommandCode Provider API（104 端点）/ CLI 1.93.0 目录（104 款，差集 0）、OpenRouter 模型与 endpoints API（目录 476 款）、各厂商官方 API 定价页（OpenAI / x.ai / 阿里云百炼 / 月之暗面 / MiniMax / 小米 / 智谱 / DeepSeek / 腾讯）。
折算汇率：1 美元 ≈ 6.7131 元人民币（中国外汇交易中心 2026-11-20 09:15 中间价；11-22 为周日无新报价，取最近交易日。每轮按实时中间价重取）。
现行口径：三档订阅——Go $10/月、Go Plus $40/月（Higher usage limits）、Go Teams $20/成员/月（逐模型额度 = Go + $5）。三档 Token 单价完全相同，仅月度额度上限不同。
🔑 额度语义（必读）：所有付费模型共用一个额度池——官方原文 “share one allowance” / “Switching models draws from the same allowance”。逐模型 Monthly limit 是**”若把全部额度只花在这一个模型上”的分母**，不可相加。
目录口径：清单 API 31 个 ID = docs 正文 31 款（差集 0）；其中 27 款付费 + 4 款免费（beam-free、hy4-flash-free、longcat-2.5-free、iceman-contributor-free）。
Plus 倍率：2x / 3x / 4x 三档，上限即 4x——清单内无任何模型超过 4x。Teams 恒为 Go + $5（加数，非乘数）。

额度定义：官方原文 “Usage limits are defined as monthly dollar amounts”，”Each model has the following usage limits: 5-hour — 20% of the monthly limit; weekly — 50%; and monthly — 100%“。Token pricing is the same for Go and Go Plus.

  • 🔑 额度是”月度美元上限 + 比例窗口”：窗口额度随模型档位自动按比例生成，不是各档独立的固定数字。三档共用同一套比例。
  • 现行 6 档分布：$15（11 款，旗舰/新模型）、$20（1 款，minimax-m3.1-flash）、$30（3 款）、$60（10 款，成熟主力）、$100（1 款，deepseek-v4.1-flash）、$500（1 款，glm-5.3 促销值）。
  • ⚠️ glm-5.3 的 $500 是促销值：官方 docs 明示 “Higher usage limits apply through November 22, 2026“。其长期档位应按 $15（Plus $60，即 4x）理解——11-23 起须重抓确认回落值。该值直接决定 Plus 的性价比结论，见第五节。
  • 为什么部分模型额度低（官方 “Why some models have lower usage”）：多数模型靠批量折扣 + 预留 GPU 容量换取高月额度；新模型或公开价本身已打折的模型无折扣空间，其额度只是”略高于直付厂商”——这是档位差异的唯一解释，不是限速。
  • 客户端要求：① 发送典型 coding agent 流量；② 自带 user agent（如 my-coding-agent/1.0），不要用通用 SDK/HTTP 库名；③ 每个会话发送稳定的 x-opencode-session 会话 ID。
    • 已验证客户端：OpenCode、Hermes（含 PR #101864 的构建）、Claude Code、Codex、ZCode、Pi、jcode（v0.81.6+）、Kilo Code CLI（含 PR #13752，不覆盖 VS Code 扩展）。
    • 已知有问题：DeepSeek Harness、GitHub Copilot Chat、Kimi Code、MiMo Code。
  • 超额处理：达月限额不自动回落，请求直接拒绝；可手动切免费模型，或开 Extra Usage 按量计费。响应头 opencode.allowance 回报本次请求计入额度的金额。
  • 订阅范围：Go / Go Plus 仅限单成员 workspace（带 Go 订阅的 workspace 无法邀请成员）；Go Teams 为 $20/成员/月、2 成员起（最低 $40/月），第二席位覆盖下一个加入者免费，期中加入收 $20 获全额，服务账号不覆盖。三档均可用 workspace credit 支付订阅/续费/升级。
  • 端点路径：全部为 https://opencode.ai/inference/go/{openai,anthropic,google}/v1*，模型清单 .../inference/go/v1/models。旧 zen/go/v1/* 仍返 200 且 ID 一致（兼容别名），新配置一律写新路径。
